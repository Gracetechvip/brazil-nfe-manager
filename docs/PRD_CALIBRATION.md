# PRD 校准记录

## 已落地口径

- 统计只使用 `invoice_company_roles` 中本公司为销售方、业务分类为 `sale`/`sales_return`、资料有授权证据且未被接受取消的发票。
- 开票日期来自 `dhEmi`/`dEmi`，以 XML 中的偏移解析后转换到公司时区；上传时间不参与期间归属。
- Model 55 以 `environment + access_key` 去重。相同身份关键金额、CNPJ 或商品字段冲突时标记 `conflict` 并暂缓统计。
- 原始文件按 SHA-256 不可变保存，版本表保留裸 NFe、`nfeProc` 和事件对象。
- SKU 与产品名筛选默认由同一商品行同时满足；发票结果只出现一次，导出仍是完整原 XML。

## 待真实样本确认

1. 各州取消事件回执的实际命名空间、`cStat` 和事件容器组合。
2. 销售退货的 CFOP/`finNFe` 规则及混合业务单据处理。
3. CNPJ 字母数字格式在业务主数据中的确认流程。
4. 飞牛硬件架构、挂载路径、票量、备份目标和权限清单。

没有上述输入时，系统会保留原文并将不确定对象标为待确认，不把它们悄悄计入销售。
