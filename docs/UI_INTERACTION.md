# 页面交互稿（V1）

左侧导航包含仪表盘、公司管理、XML 导入、发票中心、XML 筛选、XML 导出、系统管理。顶部显示当前登录用户、公司过滤器和日期范围。金额统一 BRL 两位小数，字段提示保留葡语原名。

| 页面 | 关键交互 |
|---|---|
| 仪表盘 | 公司/日期/日周月年粒度；销售、退货、净额、待确认卡片；趋势和覆盖提示 |
| 公司管理 | 搜索、新建、确认待识别 CNPJ；公司详情显示覆盖月份和累计销售 |
| XML 导入 | XML/ZIP 上传、目标公司、批次进度；重复、更新、冲突、失败可展开 |
| 发票中心 | 日期、状态、公司和分页；抽屉查看商品、事件、原始版本 |
| XML 筛选 | 金额、SKU、产品名、分类、状态组合筛选；全结果导出 |
| XML 导出 | 任务状态、快照时间、文件数、manifest、下载 |
| 系统管理 | 用户/公司授权、规则、备份、审计四个标签 |

缺少覆盖月份时显示“未导入/部分导入”，绝不以 0 代替未知。
